# FogWalker（フォグウォーカー） v2.3

> **「歩いた場所だけが、光る。」**
> 黒基調・コマンドプロンプト風の、極限ミニマル位置情報PWA。
> 現実の街を1マス＝約15mのグリッドに変換し、歩いた場所だけを白い光として描き出す。

---

## 🎮 コンセプト

- **未踏は漆黒、開拓は白光**: 背景は完全な黒（#000000）。歩いて開拓したマスだけを白い四角で描画します。
- **自機はターミナルのカーソル**: ドット絵勇者ではなく、点滅する `█` 相当のカーソル。カメラは常に自機を追従。
- **数字で見る開拓**: STREAK（連続日数）/ TILES（開拓マス数・LV）/ GLOBAL（地球全体に対する開拓率・面積）をヘッダーに常時表示。
- **完全クライアント完結・維持費0円**: サーバーなし、外部送信なし。データはすべて端末内の IndexedDB に保存されます。

## ✨ 主な機能（v2.3）

| 機能 | 内容 |
| --- | --- |
| 霧晴らし | 現在地から半径3マス（約45m・29マス）を開拓。直近のマスは高輝度、古いマスは淡くフェード。 |
| ストリーク | 連日開拓で日数が伸びる（Asia/Tokyo基準で日付判定）。 |
| レベル | 開拓マス数から LV を算出。LVアップで電子ファンファーレ＋トースト通知。 |
| 実績 | 100/500/1,000/5,000マス、1/5/10km、3/7/30日連続の10種。達成時にトースト＋SE。 |
| 今日の記録 | 今日の開拓マス数・歩行距離をフッターとメニューに表示。日付が変わると自動リセット。 |
| 7日間グラフ | メニューに直近7日の開拓マス数のミニ棒グラフ（最大60日分を履歴保持）。 |
| 軌跡ポスター | 1200×1600px の PNG を生成（白い軌跡＋タイポグラフィ統計）。共有シート対応、非対応端末はダウンロード。 |
| カラーテーマ | GRN / AMB / CYN / WHT の4色。カーソル・UIアクセント・ポスターに反映し、localStorage に保存。 |
| ズーム | 右下の `+` / `-`、マウスホイール、2本指ピンチで拡大縮小（12〜64px/マス）。 |
| GPS精度 | HIGH（高精度）/ ECO（省電力・精度の粗い測位は破棄）をメニューで切替。 |
| バックアップ | JSON で書き出し／読み込み（統合復元）。機種変更やキャッシュ削除に備えられます。 |
| オフライン | Service Worker で画面はネットワーク優先・資産はキャッシュ優先。オフライン時も記録可能。 |

### 室内テスト用

- **D-PADモード**: `MODE: GPS` ボタンで切替。画面の ▲▼◀▶ とキーボード（矢印 / WASD / スペース）で仮想移動。
- ピンチ・ホイールでのズームは D-PAD モードでも利用できます。

## 🛠️ 技術スタック

- **フロントエンド**: HTML5, Vanilla JavaScript (ES2022), Tailwind CSS (CDN)
- **描画**: HTML5 Canvas 2D API（アニメーションは requestAnimationFrame）
- **位置情報**: Geolocation API (`watchPosition`)
- **永続化**: IndexedDB `FogWalkerDB_v2`（ストア: `tiles`, `meta`）＋ localStorage（テーマ）
- **オフライン**: Service Worker（`fogwalker-v2-2`）
- **ホスティング**: GitHub Pages（無料・常時SSL）

## 🚀 使い方

1. `https://shodai4.github.io/fog-walker/` をスマホで開く（またはリポジトリ直下の `index.html` を配信）。
2. 位置情報を許可すると、歩いた場所が白く光っていきます。
3. ホーム画面に追加すると全画面のPWAとして起動できます。
4. データは端末内のみ。機種変更前に `[ MENU ] → [ EXPORT_JSON ]` でバックアップを取得してください。
