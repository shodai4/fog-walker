# FogWalker（フォグウォーカー）🗡️🗺️

> **「現実の地球を、レトロゲームのワールドマップへ。」**  
> 日常の散歩や育児のお散歩をレトロRPGの冒険に変える、世界対応・極限デフォルメ霧晴らしPWAアプリ。

---

## 🎮 コンセプト & 特徴

1. **極限デフォルメの四角いドット絵世界**:
   - 道路地図をそのまま見せるのではなく、現実の街を1マス＝約15mの均一な整数グリッドに変換。
   - レトロRPG（ファミコン・GB風）の温かみあるドット絵で街が再構築されます。
2. **歩いた場所だけ晴れる戦場の霧（Fog of War）**:
   - 未踏の地は濃霧（深いスレートグレー）。
   - スマホを持って外を歩くと、現在地から半径約90mの霧がパッと晴れて鮮やかな草原や道が現れます。
3. **道・河川・橋・スポットの自動マッピング**:
   - 現実の河川と道路が交差する場所には、木造の「橋」タイルが自動配置されます。
   - 駅、公園、神社、役所、カフェなどに近づくと「新スポット発見！」のファンファーレとともに図鑑へ登録。
4. **完全クライアント完結・維持費0円（個人開発の極み）**:
   - サーバー代、API代、ライセンス代は完全ゼロ。
   - バックエンドを持たず、ブラウザの IndexedDB にすべての開拓データを安全にローカル保存。
   - 外部サーバーに位置情報が送信されないため、プライバシーも100%保護されます。
5. **PWA（Progressive Web App）対応**:
   - iOS Safari / Android Chrome で「ホーム画面に追加」するだけで、ネイティブアプリ同様に全画面起動・オフライン動作。
   - 室内テスト用の「仮想D-Pad（十字キー）」「キーボード移動」機能も完備。

---

## 🛠️ 技術スタック

- **フロントエンド**: HTML5, Vanilla JavaScript (ES2022), Tailwind CSS
- **描画エンジン**: HTML5 Canvas 2D API（軽量・省電力・バッテリー長持ち）
- **位置情報**: Geolocation API (`watchPosition`)
- **データ永続化**: IndexedDB (`FogWalkerDB` v1)
- **ホスティング**: GitHub Pages (完全無料・常時SSL)

## 🚀 使い方・動作確認

1. **GitHub Pagesで動かす場合**:
   - 本リポジトリをGitHubにプッシュし、Settings > Pages で `main` ブランチを指定して公開します。
   - 発行されたURL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）をスマホで開くだけで即起動します。

2. **操作方法**:
   - **リアルGPSモード**: 外を歩くだけで自動的に自機が追従し、周囲の霧が晴れます。
   - **仮想パッドモード**: 画面右下の🎮ボタンをタップすると、画面上のD-Pad（▲▼◀▶）やキーボードの矢印キー（W/A/S/D）で自由に歩き回って霧晴らしをテストできます。
   - **📜 メニュー**: 開拓マス数、踏破距離、レベル、発見したスポット図鑑、JSONデータ書き出し・初期化が行えます。
